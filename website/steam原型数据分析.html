01
三层解耦定位模型
Three-Layer Decoupled Positioning
任何产品拆成 L-Core（玩法） / L-Mid（叙事） / L-Skin（美术·文化） 三层；任一层替换不影响其他层。立项时先画这三层，进不同区域只换 L-Mid / L-Skin。
✓ 应用：A 港口（开箱·拍卖·地区美术）/ H 深海（出海·守望·克苏鲁 vs 北欧）/ I 动物（营救·庇护所·温暖 vs 都市）
✗ 反例："禁酒令 + 美式帮派"把玩法和文化绑死，进中东 / 穆斯林市场时无法调整。
AHI
02
分钟级解锁铁律
Minute-by-Minute Unlock Discipline
前 60 分钟 / 前 21 天，每一分钟 / 每一天 都明确回答：核心爽点是什么 · 新概念解锁是什么 · 情感钩子是什么。立项文档必须有网格表。
✓ 应用：A 0-60 分钟每分钟一个新概念 + 每 3 分钟一次开箱；G 禁酒令 D0-D21 每天一个主爽点 + D7/D14/D21 三次毕业仪式
✗ 反例："第一小时玩家体验核心玩法"这种抽象描述 — 落不到实际帧上。
AG
03
概念转移与新手保护
Concept Handoff & Newbie Protection
新概念 B 解锁时，旧概念 A 至少自动化 70% 或消失；每次关键升级后给玩家 至少 10 分钟 纯体验期（不再塞新东西），关键资源自动补满。
✓ 应用：A 开第 2 家店时第 1 家自动化只保留"收入通知"；E 新系统开启时旧系统自动演示 3 次
✗ 反例：D7 同时开新店 + 新收纳 + 新装修 + 新会员 + 新员工 — 玩家"晕"。
AE
04
情绪节拍架构
Emotional Beat Architecture
情感钩子不是"某个等级触发"，而是在玩家 情绪曲线的正确位置 触发 — 玩家不会在开心时接受悲伤，不会在疲惫时接受深度；会在平静时接受转折。
✓ 应用：E 父亲笔记 P2 不是 D3 固定触发，而是"玩家买 10 次盒子毫无收获时的那一刻"
✗ 反例："D3 触发悲伤剧情" — 玩家可能正在开箱爽到天，根本不接受。
E
05
身份连续性模型
Identity Continuity Model
身份升级是 累积，不是切换：核心资产跨身份永久有效 · UI 不换新内容叠加旧内容 · 新身份保留旧身份不是抛弃。
✓ 应用：E 店主 → 经理 → IP 颠覆者，UR 卡永久保留；G T1 蒸馏工 → T5 议员，第一家店吧台永久保留；I 庇护所 → 联盟总部，所有动物永久陪伴
✗ 反例："D30 后你不再是店主，你是经理" — 玩家感受是 被剥夺，而不是被晋升。
EGI
06
核心资产保险
Core Asset Shield
玩家的核心稀有资产（UR 卡 / 救助过的动物 / 家族核心 NPC）必须 永久保险：主场易手 / 服务器合并 / 版本更新都不能剥夺。
✓ 应用：E UR 卡在主场易手时不被转移；I 救助过的动物在战斗失败时不会死亡
✗ 反例："Boss 战失败你会失去一位队友" — 玩家感受是被惩罚，直接弃游。
EI
07
多轨路径 + 退出口
Multi-Path & Escape Routes
重度内容（SLG / PvP / 高压战斗）必须有 至少 2 条路径 到达同一目标，其中 1 条是"轻度路径"（单机党 / 社恐党可走），所有路径同终点。
✓ 应用：G D21+ 单机派 95% 机制共享只缺 PvP；I 三路径玩家获得同等动物收益，只是战斗强度不同；A 4 阶段 SLG PvE 优先
✗ 反例："只有 PvP 才能获得终局内容" — 70% 玩家被挡在门外。
AGI
08
渐进式投放
Gradual Deployment
重度玩法（SLG / 高压战斗 / 深度策略）不要一次性投放：PvE 展示 → 轻 PvP → 中 PvP → 重 PvP 四阶段，每阶段之间 ≥ 3 天稳定期。
✓ 应用：A PvE 10 天 → 轻 PvP 5 天 → 中 PvP 5 天 → 重 PvP 可选；G D21 家族会议让玩家选单机 / 社交派
✗ 反例："D15 开联盟战 + D15 开跨服 PvP + D15 开赛季" — 玩家被海量机制淹没。
AGI
09
借鉴多源的单一主导
Single-Dominant Reference
多个借鉴源（MPH + DREDGE + 克苏鲁 + Frostpunk）必须明确 1 个主导（70%+） + 2-3 个辅助点缀（单一机制片段，剥离原语境）。
✓ 应用：H 深海守望者 = MPH 主导 70% + DREDGE 异常鱼 + 克苏鲁视觉线索 + Frostpunk 灯油计
✗ 反例："玩法 = MPH 40% + DREDGE 30% + Frostpunk 30%" — 玩家感受是"四不像"。
H
10
内容生产并行化
Parallel Content Production
60+ 天留存需多条并行内容线（主线 / 支线 / LiveOps），不把内容压在单一线上；任何单点失败不让整个产品崩盘，各线共享资产减少成本。
✓ 应用：I 三条内容线并行（主线季度 1 新篇 + 支线反派每月 + LiveOps 社区每周）
✗ 反例："一条主线 8 章故事 + 无其他内容" — 剧情团队 burnout = 产品停更。
