SLG 立项判断体系 · 轻量化演变与优质项目标准
结论先行：好项目不是“更像传统 4X”，而是“用更低门槛承接更长期的战争与社交”

读完原型和商业化适配后，这一页把判断方法抽象成立项标准。判断一款外部 SLG 产品是否值得立项，不能靠题材新鲜感、商店标签或广告截图。核心问题只有一个：它是否在用户更偏好轻量入口的趋势下，仍然能保留 SLG 的长期目标、社会压力和可商业化深度。

本页不再使用二元标签。统一按重度 SLG、轻量化 SLG和轻量化颗粒度来判断；所有结论必须回到维度、数据和可验证标准。

外部公开证据：为什么要从“重度”转向“轻量化”判断
4X 仍是高商业化品类，但学习曲线和流失压力高
Google Play 的 4X Strategy genre report 明确把 4X 定义为高商业化、同时高学习门槛的品类；因此优质判断不能只看后端深度，还必须看新手期是否把复杂度拆开。
赛道演变正在从“SLG+X”走向“X+SLG”
点点数据 2025 全球 SLG 报告把趋势概括为从“SLG+X”转向“X+SLG”：先用生存、经营、塔防、卡牌或射击等入口降低理解成本，再把 SLG 后端放到中后期承接。
买量不是附属项，素材边界会反过来决定模型
DataEye 与 XMP/Mobvista 的 2025 买量报告都指向一个现实：策略/SLG 仍在头部收入中占重要位置，但创意、渠道和素材效率越来越决定项目能否放量。

一、轻量化颗粒度：先确定它到底轻在哪里
重度 SLG传统 4X / 高压战争前置
主城、行军、联盟、侦查、掠夺、治疗、护盾、赛季、跨服等系统早期就直接暴露。它不是错误方向，但需要成熟 SLG 团队、高预算买量和强运营能力。
证据：学习成本、D0 流失、联盟组织率、战损压力、护盾/治疗/迁城消耗。
COK-like ROK-like

中度轻量轻入口 + 可感知成长

WOS-like Last Asylum-like Top Heroes-like
共同点是基地、英雄、设施或队伍已经可见，但战争失败先被“生存、职业、探索、领地成长”解释。
复合玩法轻量化玩法钩子承担理解门槛
三消、射击、塔防、合并、经营、卡牌或检查识别先解释“我为什么变强”，后端再接联盟、地图、赛季与资源竞争。关键是钩子与本体不能断裂。
证据：广告承诺与实机一致度、D7 后端开启率、活动参与率、差评中是否出现“货不对板”。
Kingshot / Kingdom Guard-like Puzzle 4X-like 疯狂水世界-like Top War-like
归类依据是塔防、三消、经营卡牌或合并升级承担第一层理解成本；后端仍可接联盟、赛季和战争。
包装层面轻量化表层轻，核心仍重
广告、美术或新手期看起来休闲，但付费与长期目标很快回到传统重度 4X。它可以做，但不能误判为低成本机会，必须按重度项目估预算。
证据：早期差评、付费坑位密度、联盟战开放时间、CPI 相对基准、核心用户与广告用户重叠度。
Evony-like Mafia-like Lords Mobile-like Dragon / Beast-like Ecology-like IP / Faction Season-like
这些样本可以用谜题、身份、IP、伙伴或生态题材软化表达，但付费深水层仍按中高到重度 SLG 估算。
二、立项倾向：不是四类平权
结论：优先选“复合玩法轻量化”或“中度轻量”，极轻量先做入口测试，包装层面轻量化只做条件立项
这不是“极轻量 > 中度轻量 > 复合轻量”的线性优劣，而是看它能不能同时解决获客门槛和 D7-D30 后端承接。Google Play 把 4X 定义为高商业化但高学习曲线；AppMagic 2026 显示 4X 仍是策略品类主驱动；Kingshot / WOS 的成功则说明新品更需要用 X+SLG 的方式把复杂度后置。
推荐排序：复合轻量化 → 中度轻量 → 极轻量 → 包装轻量

1 复合玩法轻量化 优先级最高 有明确副玩法钩子：塔防、三消、经营、卡牌、合并、射击，并且能自然接联盟 / 赛季 / 地图。 钩子和 SLG 后端断裂，玩家觉得广告和实机不一致。 最符合从“SLG+X”转向“X+SLG”的趋势；先用玩家熟悉的动作解释变强，再逐步打开 SLG 后端。
2 中度轻量 优先级很高 题材本身能解释基地、英雄、队伍、设施成长，例如生存、避难所、探索、职业身份。 买量不如极轻量锋利，需要更强内容、中期留存和后端节奏能力。 不是最轻，但最稳；适合要做长期商业化，而不是只测素材点击的方向。
3 极轻量 适合入口验证 快速测 CTR / CVR / D1 / 前 10 分钟完成率，例如跑道射击、短局塔防、开箱、合并。 只有入口爽感，没有 D7-D30 后端，会变成素材项目或短命产品。 可以作为买量入口和首日验证，不宜单独当完整 SLG 方案；Last War 的关键是极轻入口后面接了重度 4X 后端。
4 包装层面轻量化 谨慎 / 条件立项 团队本来就能做重度 SLG，或有强 IP、强买量预算、成熟运营能力。 表面轻、核心重，容易误判成本；预算、团队、运营、战损、联盟组织都仍按重度项目估。 不是不能做，而是不能当“轻量项目”做；Evony / Mafia / Lords Mobile-like 更像重度项目的表层软化。
落到当前 9 个方向：A 港口、E 卡店、J 防疫区优先从复合玩法轻量化或极轻量入口验证切入，但必须在样本里补 D7-D30 后端；B 酒店、C 拳馆、I 动物联盟更适合中度轻量；G 禁酒令和 D Nightking 如果走 Mafia-like 或传统 4X 包装轻量，必须先按高 CPI、素材竞争和重 SLG 运营成本估算。

五、硬门槛：命中就不应直接立项
没有外部证据
只有概念、情绪或单条素材灵感，没有同类产品、用户评论、广告素材或可玩样本支撑，最多进入观察池。
轻入口与后端断裂
广告像经营/射击/开箱，付费和留存却突然变成传统重度战争，用户会把它理解为货不对板。
题材解释不了战争压力
如果题材里没有外部威胁、资源争夺或抱团理由，就很难自然长出联盟、地图、赛季和 PVP。
商业化只剩硬塞
付费点无法从身份、资产、设施、角色或失败原因里长出来，只能卖泛化战力，说明题材没有承担商业化解释力。
关键数据不可得
评论、留存、买量、战斗规则或付费结构不能确认时写 unknown / 数据未公开；不能用猜测补成结论。
六、外部产品快判流程
1. 先归类
判断它是重度 SLG，还是四类轻量化中的哪一类。不要先问“像不像 SLG”，先问“它把复杂度藏在哪里”。
2. 拉证据
至少收集商店页、评论、广告素材、实机录屏、社区反馈和可见系统结构；每条判断都要能回到来源。
3. 拆三层循环
日常动作、外部威胁、抱团理由三层都成立，才有资格说它能长成轻量化 SLG。
4. 过评分表
8 维满分 100，尤其要单独检查入口人群与后端压力是否匹配；不要用某个题材的个人好感覆盖数据缺口。
5. 决定动作
高分进入可玩验证，中分做小额素材或机制样本，低分只进观察池；硬门槛命中则直接暂停。
80-100：可进入立项验证仍需 4-8 周样本，不等于直接进完整项目。
65-79：小样本验证先验证最大不确定性，如 CPI、首局完成率或后端承接。
50-64：观察 / 补证方向可能有潜力，但证据链还不足以消耗团队主力资源。
<50 或硬门槛命中：不立项记录原因，保留为竞品监控或素材学习对象。
与当前 9 个方向的关系：A 港口、E 卡店、J 防疫区更适合从极轻量或复合玩法轻量化开始验证；B 酒店、C 拳馆、I 动物联盟更适合先做中度轻量和身份/角色养成；G 禁酒令和 D Nightking 需要特别关注买量素材成本，其中 D 的核心问题不是“能不能做成 SLG”，而是高 CPI、素材竞争和预算验证压力。

结论先行：这里的轻重度主要指中后期后端，不指前 10 分钟入口

Q1
玩家主城能不能被其他玩家攻打？
能被打、会燃烧、会触发迁移或护盾消耗，说明后端偏重；只是生产中心 / 经营领地，说明更偏轻量化经营或角色养成。
Q2
是否有全天候行军、派兵与资源掠夺？
24h 大地图行军偏重度后端；每天固定 1-2 小时城战或宣战窗口，更偏接地型轻量化 SLG 或活动化 PVP。
Q3
付费核心卖什么？
卖建造、训练、治疗、迁城、护盾、VIP，说明战争效率是核心；卖英雄抽卡、升星、装备、阵容包，说明角色/卡牌数值是核心。

飞城 / 飞地类型对商业化的影响
1. PVP 节奏
自由飞城会制造突袭、夜袭、零点事件和高压护盾管理；接地飞地把战争变成前线推进、堵路和宣战节奏；限时节点战则把 PVP 压进固定窗口，更像活动。
2. 商业化目标
自由飞城更容易卖迁城、护盾、治疗、行军加速和战备包；接地飞地更适合卖赛季通行证、路线收益、联盟科技和前线建设；限时节点战更适合卖体力/耐久、战令和阵容包。
3. 养成强度
自由飞城要求个人战力、医院、兵量、反侦察和联盟在线率都够硬；接地飞地把压力拆到路线、据点和联盟管理；限时节点战可以把强度压到英雄、队伍和活动科技，不必早期暴露永久战损。
4. 玩家易接受度
自由飞城的刺激最大，但新手被打退坑风险也最大；接地飞地更容易解释“为什么这里会打起来”；限时节点战最容易被轻用户接受，因为失败更像一次活动失利，而不是家被偷了。
对当前 9 个题材的后端落点：A 港口、E 卡店、B 酒店、C 拳馆更适合先用经营卡牌轻后端或接地飞地做低门槛验证；J 防疫区、H 深海可以借 WOS / Kingshot 的重度后端轻入口包装，但不要 D0 就开放自由飞城；G 禁酒令和 D 毒枭原型商业化上能接 Mafia / COK，其中 D 的主要风险按黑帮买量 CPI 高与素材竞争强处理。判断不是“哪个更 SLG”，而是“哪种中后期战争压力能被题材自然解释，并且能服务 D0-D7 投放和软验证”。

下游沉淀：10 条可复用设计原则（由 5 项目修订抽象）
  1. 三层解耦定位模型 — L-Core（玩法） / L-Mid（叙事） / L-Skin（美术文化），任一层替换不影响其他层
  2. 分钟级解锁铁律 — 前 60 分钟 / 前 21 天每一分钟都写明核心爽点 + 新概念 + 情感钩子
  3. 概念转移 + 新手保护 — 新概念解锁时旧概念自动化 ≥ 70%，关键升级给 10 分钟纯体验期
  4. 情绪节拍架构 — 情感钩子在玩家情绪曲线的正确位置触发（不是等级触发）
  5. 身份连续性模型 — 身份升级是"累积"不是"切换"，核心资产跨身份永久有效
  6. 核心资产保险 — 稀有卡 / 动物 / 家族 NPC 等关键资产永久不被剥夺
  7. 多轨路径 + 退出口 — 重度内容至少 2 条路径（轻度 + 中度），一条单机党可走
  8. 渐进式投放 — SLG / PvP 分 4 阶段（PvE → 轻 PvP → 中 PvP → 重 PvP），每阶段 3 天稳定期
  9. 借鉴多源的单一主导 — 1 个主导借鉴（70%+） + 2-3 个辅助点缀（单一机制片段）
  10. 内容生产并行化 — 60+ 天留存需多条并行内容线（主线 / 支线 / LiveOps），共享资产

01
三层解耦定位模型
Three-Layer Decoupled Positioning
任何产品拆成 L-Core（玩法） / L-Mid（叙事） / L-Skin（美术·文化） 三层；任一层替换不影响其他层。立项时先画这三层，进不同区域只换 L-Mid / L-Skin。
✓ 应用：A 港口（开箱·拍卖·地区美术）/ H 深海（出海·守望·克苏鲁 vs 北欧）/ I 动物（营救·庇护所·温暖 vs 都市）
✗ 反例："禁酒令 + 美式帮派"把玩法和文化绑死，进中东 / 穆斯林市场时无法调整。
AHI
02
分钟级解锁铁律
Minute-by-Minute Unlock Discipline
前 60 分钟 / 前 21 天，每一分钟 / 每一天 都明确回答：核心爽点是什么 · 新概念解锁是什么 · 情感钩子是什么。立项文档必须有网格表。
✓ 应用：A 0-60 分钟每分钟一个新概念 + 每 3 分钟一次开箱；G 禁酒令 D0-D21 每天一个主爽点 + D7/D14/D21 三次毕业仪式
✗ 反例："第一小时玩家体验核心玩法"这种抽象描述 — 落不到实际帧上。
AG
03
概念转移与新手保护
Concept Handoff & Newbie Protection
新概念 B 解锁时，旧概念 A 至少自动化 70% 或消失；每次关键升级后给玩家 至少 10 分钟 纯体验期（不再塞新东西），关键资源自动补满。
✓ 应用：A 开第 2 家店时第 1 家自动化只保留"收入通知"；E 新系统开启时旧系统自动演示 3 次
✗ 反例：D7 同时开新店 + 新收纳 + 新装修 + 新会员 + 新员工 — 玩家"晕"。
AE
04
情绪节拍架构
Emotional Beat Architecture
情感钩子不是"某个等级触发"，而是在玩家 情绪曲线的正确位置 触发 — 玩家不会在开心时接受悲伤，不会在疲惫时接受深度；会在平静时接受转折。
✓ 应用：E 父亲笔记 P2 不是 D3 固定触发，而是"玩家买 10 次盒子毫无收获时的那一刻"
✗ 反例："D3 触发悲伤剧情" — 玩家可能正在开箱爽到天，根本不接受。
E
05
身份连续性模型
Identity Continuity Model
身份升级是 累积，不是切换：核心资产跨身份永久有效 · UI 不换新内容叠加旧内容 · 新身份保留旧身份不是抛弃。
✓ 应用：E 店主 → 经理 → IP 颠覆者，UR 卡永久保留；G T1 蒸馏工 → T5 议员，第一家店吧台永久保留；I 庇护所 → 联盟总部，所有动物永久陪伴
✗ 反例："D30 后你不再是店主，你是经理" — 玩家感受是 被剥夺，而不是被晋升。
EGI
06
核心资产保险
Core Asset Shield
玩家的核心稀有资产（UR 卡 / 救助过的动物 / 家族核心 NPC）必须 永久保险：主场易手 / 服务器合并 / 版本更新都不能剥夺。
✓ 应用：E UR 卡在主场易手时不被转移；I 救助过的动物在战斗失败时不会死亡
✗ 反例："Boss 战失败你会失去一位队友" — 玩家感受是被惩罚，直接弃游。
EI
07
多轨路径 + 退出口
Multi-Path & Escape Routes
重度内容（SLG / PvP / 高压战斗）必须有 至少 2 条路径 到达同一目标，其中 1 条是"轻度路径"（单机党 / 社恐党可走），所有路径同终点。
✓ 应用：G D21+ 单机派 95% 机制共享只缺 PvP；I 三路径玩家获得同等动物收益，只是战斗强度不同；A 4 阶段 SLG PvE 优先
✗ 反例："只有 PvP 才能获得终局内容" — 70% 玩家被挡在门外。
AGI
08
渐进式投放
Gradual Deployment
重度玩法（SLG / 高压战斗 / 深度策略）不要一次性投放：PvE 展示 → 轻 PvP → 中 PvP → 重 PvP 四阶段，每阶段之间 ≥ 3 天稳定期。
✓ 应用：A PvE 10 天 → 轻 PvP 5 天 → 中 PvP 5 天 → 重 PvP 可选；G D21 家族会议让玩家选单机 / 社交派
✗ 反例："D15 开联盟战 + D15 开跨服 PvP + D15 开赛季" — 玩家被海量机制淹没。
AGI
09
借鉴多源的单一主导
Single-Dominant Reference
多个借鉴源（MPH + DREDGE + 克苏鲁 + Frostpunk）必须明确 1 个主导（70%+） + 2-3 个辅助点缀（单一机制片段，剥离原语境）。
✓ 应用：H 深海守望者 = MPH 主导 70% + DREDGE 异常鱼 + 克苏鲁视觉线索 + Frostpunk 灯油计
✗ 反例："玩法 = MPH 40% + DREDGE 30% + Frostpunk 30%" — 玩家感受是"四不像"。
H
10
内容生产并行化
Parallel Content Production
60+ 天留存需多条并行内容线（主线 / 支线 / LiveOps），不把内容压在单一线上；任何单点失败不让整个产品崩盘，各线共享资产减少成本。
✓ 应用：I 三条内容线并行（主线季度 1 新篇 + 支线反派每月 + LiveOps 社区每周）
✗ 反例："一条主线 8 章故事 + 无其他内容" — 剧情团队 burnout = 产品停更。
I

一、会议形成的三层判断框架
1
吸量不是只看低 CPI

低 CPI 必须和题材调性一致。泛用户便宜不代表长线可做，素材要能带出建造、生存、对抗或明确的成长压力。

2
玩家初衷要接 SLG 目标

用户进来想要的事情，必须能自然延展到经营、扩张、组织、冲突和联盟；否则 D0 吸量和 D30 长留会断开。

3
核心反馈要强且可视化

非战斗 SLG 也要有强反馈：生产、服务、清理、筛查、建造、升级、并购、守线，都要能被用户一眼看懂。

4
关键元素要能映射后端

题材里的关键对象要能变成英雄、队伍、设施、资源、地盘或赛季目标；只有入口轻，后端不能轻到没付费深度。

三、合作推进门槛
方向精修

发行方先把 G / J / E 的题材、核心玩法、影片素材和画风参考拆成可投放脚本，研发方判断玩法与素材是否匹配。

买量验证

用真实玩法画面或高保真视频做小额投放，核心看调性正确的 CPI、CTR、CVR、D1/D7 早期信号，而不是只看便宜用户。

MVP 纯净版

若素材验证成立，3 个月内拆一个可运行版本，预算口径约 200-300 万，包含内外层功能但不追完整引导和章节任务。

D7 / S1 决策

D7 测试版约 7-8 个月；第一赛季结束版本再加 3-4 个月。只有当吸量、留存和回本模型同时过线，才进入完整合作。

  • ① 题材受众极度区域化：同是"叙事经营"，Beholder 俄语 38.8% 而 TCG Card Shop 俄语仅 2.6%。题材选择必须先看 Steam 语言分布而不是脑补。

  • ③ 拆包/开箱是跨文化通用爽点：Schedule I（毒品拆包）97%、TCG Card Shop（卡牌拆包）97%、Storage Hunter（仓库拆包）79%——跨题材全部高分。港口开箱方向有天然普适性。
  • ④ 玩法骨架可迁移，题材必须本地化：Schedule I 的"生产-分销-体验"骨架放到禁酒令 / 茶叶走私 / 咖啡黑市都能跑通，关键看买量成本与文化共鸣。
  • ⑤ 英语区永远是基本盘：9 个 Steam 原型合计英语占比最高，任何海外项目的第一用户必须是英语玩家。中文/日韩是加分项而非主盘。
  • ⑥ 买量成本决定模型，不是题材好坏：Schedule I 原味爽感拉满（97% 好评 / 45.9 万峰值），D 可以用 Mafia-like 黑帮买量承接，但 CPI 可能很贵。任何题材上马前必须先做成本情景表（方向 G 禁酒令 vs 方向 D 原味毒枭是低成本与高成本路径对比）。
