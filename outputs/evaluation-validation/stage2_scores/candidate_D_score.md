## 4. Verdict

Score: 77/100. Decision band: Small-sample validation.

The material is valuable as a reference for front-end lightening techniques, but it should be treated as two validation directions, not one unified greenlight. The score reflects concept-transfer quality rather than proof that either exact path is ready.

## 5. Main Risks

- Merge users and adventure users are different acquisition pools; combining them can blur product definition.
- Front-end simplicity may overpromise if D7+ alliance pressure arrives too abruptly.
- Top Heroes-specific troop, migration, and war details remain uncertain.
- A dual-sample pitch can hide roadmap tradeoffs that a single concept would need to resolve.

## 6. What Would Need Validation First

- Choose one path before validation: merge-military or hero-exploration fantasy.
- For the chosen path, build a D0-D7 playable flow and map exact D7+ handoff to alliance/map objectives.
- Verify war pressure, casualty/migration rules, and ad-to-game fidelity for the selected front-end hook.
