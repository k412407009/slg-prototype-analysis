# Candidate C：Last Asylum: Plague / 乌鸦医生

## 1. 一句话立项假设

用“瘟疫医生 + 黑暗中世纪医院 + 鼠群防线”把 4X 前端包装成救治与防守：D0-D1 先建病房、熬草药、收容患者、挡鼠潮，D2-D7 做避难所经营和职业英雄，D7-D30 转资源前哨、废墟城市、联盟地图和疫区争夺。当前资料反推，早期版本待核验。

## 2. 题材与玩家身份

玩家是瘟疫世界里最后庇护所的医生或管理者。题材关键词包括鸟嘴面具、草药、病床、患者、鼠群、Rat King、防御塔、废墟城镇和最后避难所。身份起点不是“我要征服”，而是“我要治病、挡灾、让人活下去”。这能自然解释病房扩建、药材生产、幸存者部署、英雄职业和防线升级。

## 3. D0-D1 前端入口

D0 第一屏应是破败医馆和染病幸存者。玩家搭病床、熬草药、分配幸存者岗位，处理第一批患者；随后出现鼠群防守，玩家建塔、释放英雄技能、守住医馆。D1 目标是扩病房、采木材/药草/食物、建设住宅和仓库、派小队侦察废墟。首日付费不应直接卖兵种战力，而应卖“多救一个人”和“守住这一波”的可见改善。

## 4. D2-D7 养成与留存

D2-D7 从医馆变成庇护所经营。玩家升级病房、仓库、住宅、草药工坊、防御塔和探索队列，维持治疗效率与资源经济。英雄可分成医生、守卫、猎鼠者、炼金师等职业，用于防守、探索、试炼和资源回收。Pocket Gamer 新手指南强调早期经济和幸存者部署，因此这阶段应少堆 4X 菜单，多做资源缺口、职业搭配和鼠群挑战。

## 5. D7-D30 SLG/联盟/地图后端

D7 后地图目标可以解释为“收复疫区”：联盟共同清理废墟、占领资源前哨、控制城市道路和安全区。鼠群/瘟疫事件提供公共 PvE，废墟城市和稀缺药材点提供 GvG。后端必须避免“医生突然变军阀”的断裂，战争逻辑应是控制药材、道路和城市，庇护所才能救更多人。传统兵种、克制和永久战损未找到稳定证据，保留待实机核验。

## 6. 商业化锚点

首充可给可靠助手、医生英雄或关键药方；经营包卖草药、食物、病房加速、自动采集和治疗效率；英雄池卖医生、猎鼠者、守卫碎片；塔防层卖防御塔材料、鼠群挑战通行证和技能书；联盟活动卖废墟争夺、公共鼠潮、联盟贡献礼包；外观卖医馆皮肤、乌鸦、鼠疫主题头像框和英雄皮肤。D1/D7/CPI/LTV 均 unknown。

## 7. 买量素材角度

素材角度包括四组：瘟疫医生强人设；药方选择题，选错病人恶化，选对则治愈入队；密集鼠群冲击医馆的塔防；小队进入废墟城镇清理感染区。广告需要展示真实医馆、草药、鼠群和防御塔，不宜只靠电影感鸟嘴面具。社区广告讨论可作为落差风险观察，不能当玩法证据。

## 8. 关键风险与未知项

主体链路在公开渠道有不同表述，发行/开发归属需进一步核验。疾病、瘟疫、患者表现可能有素材敏感性；医馆经营用户是否接受 D7 后联盟地图也未知。早期版本、软启动地区、首日流程、功能开放表、D1/D7 留存、CPI/LTV、传统兵种/战损规则均 unknown。当前资料反推，早期版本待核验。
