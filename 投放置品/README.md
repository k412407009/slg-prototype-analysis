# 时间差、预测精度与心智迁移 · 一个 SLG 研发的投放札记

> 一个五篇连载的系列，给"丁开心的游戏观察"公众号。

---

## 一、系列定位

**谁在写**：丁亮（笔名：丁开心）——一个游戏研发出身的制作人，不是老牌投放老炮，也不是买量 KOL。这是一份"研发视角的买量札记"。

**写给谁**：游戏行业从业者。研发、发行、投放、运营、老板都看得懂，但侧重让研发的人读完有"原来这边是这样"的醍醐灌顶感，让投放的人读完有"这小子还挺懂"的会心一笑。

**主题脉络**：一场发生在饭桌上的争论——投放人员说"自动化了"，运营说"你们这帮人没成长"，SLG 老板说"我们赚的是时间差"。到底谁说的对，多出来的利润是从哪里变出来的，一个研发怎么理解这个生意，以及一个研发主导的立项团队该怎么选品。

**阅读顺序**：五篇层层嵌套，推荐顺序阅读，但每一篇也能独立成稿。每篇都会显式回收前几篇的概念，像一个跨篇的认知工程。

### 01 · 买量三论

> logline：投放人员说"自动化了"，运营说"你们没成长"，SLG 老板说"我们赚时间差"。到底谁说的是实话？

提出「套利红利 = 预测精度差」这个核心框架，做一份"三种论的水分评估表"，把这场争论按真实度排序。本篇是整个系列的入场券，后面四篇都会回收这个框架。

### 02 · 机器学习的午夜

> logline：如果买量是在算法这台机器旁边捡钱，那我们得先知道它在哪里不准、什么时候不准。

从工程师视角讲清楚：pLTV 为什么会错、冷启动窗口为什么存在、2026 年这个窗口缩短到了什么程度、老练的团队怎么"主动制造扰动"让算法持续在学。这是系列里最"技术"的一篇，但用文学笔法写。

### 03 · 两段式骗局

> logline：Last War 用推门素材骗进来的人，到 D60 时 ARPU 为什么不比 Whiteout Survival 低？这不是骗算法——是骗"算法以为它懂的那个用户画像"。

Last War / Whiteout Survival / Top War 三家对照——同样是 Hybrid-Casual SLG 赛道，三种完全不同的哲学（买量套利派 / 全场景融合派 / 原生融合派）。推门素材的"骗算法原理"在这一篇拆解清楚。

### 04 · 七日渡河

> logline：一个冲着 My Perfect Hotel 风格推门素材进来的玩家，怎么在 D7 之前从"这好像是个休闲游戏"变成"我得赶紧升联盟"而不觉得被骗？

"渐进露出"的设计方法论——D1-D7 每天的体验变化、6 个必做的 A/B 测试、三段式心智迁移框架。这是研发视角最能发挥的一篇。

### 05 · 选品四周

> logline：一个没做过发行的研发拿到立项机会，该怎么选题材？

四周漏斗 SOP：第 1 周五维打分、第 2 周三故事验证、第 3 周机制反推、第 4 周买量可行性预评估。配套 Python 工具包已做好（见 `轻量化SLG赛道/世界观选品SOP/`），本篇是它的"叙事化导读 + 方法论论证"。

## 五、写作风格参数

本系列统一走风格配比 **水母 50% / Dennis 50%**（平衡版）。这不是默认的 70/30，原因是：

- 题材本身涉及 UA/买量这种"实操密度很高"的内容，水母纯学者腔会让买量同行觉得"你不懂"
- 但又是一个研发视角的"认知工程"，需要水母的"造概念+跨篇迭代"能力，否则会变成单纯的 Dennis 式行业讲座

50/50 的效果按 `style-dna.md` 第 9.3 节：
- 标题：混合式（概念 + 数据钩子）—— 本系列主标题走古典三组四字，每篇副标题给足具体性
- 数据密度：每节至少 1 个数据（Dennis 侧要求）
- 口语化：7 分（中偏口语）
- 结尾：洞察 + 行动建议（既要诗意也要落地）
- 造概念：每篇至少 1 个可跨篇回收的新词
- 比喻：画面感强，水母学者型类比 + Dennis 生活化比喻各占半壁

### 三层过滤 Prompt（写作时贴给 AI）

```
第一层 · 我是谁
  丁亮，游戏公司研发出身的制作人，现在做微信/抖音小游戏和原生 APP。上海。
  笔名"丁开心"。姿态：一个还在一线做事的人把想法写出来给同行看，不是导师、
  不是 KOL。目标读者：研发、发行、投放、运营、老板。

第二层 · 风格配比 50/50
  水母花生 50% + DennisLook 50%，参数详见 style-dna.md 第 9 章。
  - 开头必有诗词/名著/电影引用做调性锚点
  - 造概念要可以跨篇迭代
  - 每节至少挂 1 个硬数据
  - 术语英文直接上（CPI/LTV/pLTV/VO/AEO/tROAS/eCPM 等）
  - 正文 80% 冷分析 + 20% 暖收尾
  - 比喻混用（水母学者型 + Dennis 生活化）

第三层 · 去 AI 味
  严格按 写作指南/反AI味提示词库.md 第 8 章 Checklist 过稿。重点自检：
  - 黑名单词（值得注意的是/深入探讨/至关重要/凸显了/彰显了/焕发新生…）
  - 三件套排比"A、B 和 C"改为不对称结构
  - "不是 X 而是 Y" 全文 ≤ 2 次
  - 段首总结句 ≥ 1/3 改为细节/案例/问题开头
  - 结尾不空洞升华
  - 加粗 ≤ 段落数 1/5
  - 正文无 emoji
  - 一段破折号 ≤ 2 处
  - 大声朗读自检
```

### 本系列禁用词扩展版

在 `反AI味提示词库.md` 基础上，本系列额外禁用以下涉及买量业话的套路表达：

| 禁用 | 原因 | 替代 |
|---|---|---|
| 买量内卷到极致 | 陈词滥调 | 用具体数据说卷到什么程度 |
| 红海 / 蓝海 | 过度简化 | 描述具体的竞争格局 |
| 赋能 / 抓手 / 颗粒度 | 互联网黑话 | 直接说事 |
| 流量密码 | 营销号腔 | 说清楚具体是什么信号 |
| 下半场 / 新赛道 | 空话 | 讲清楚前后的变化 |
| 解锁新场景 | 正确的废话 | 说具体新做了什么 |
| 回归本质 | 空洞升华 | 说清楚"本质"具体指什么 |

## 七、快速上手

### 1. 生成配图（一键）

```bash
cd /Users/ahs/Desktop/Git/personal-assistant/丁开心的游戏观察/drafts/SLG专题/投放札记

# 跑第 01 篇的所有图（概念图 + 信息图 + 游戏截图）
python3 scripts/build_series_assets.py --plan 01

# 跑所有篇（按顺序）
python3 scripts/build_series_assets.py --all

# 只跑生图，不碰游戏素材
python3 scripts/build_series_assets.py --plan 01 --images-only

# 只抓游戏素材，不生图
python3 scripts/build_series_assets.py --plan 01 --games-only

# dry-run（只打印会执行的命令，不真正跑）
python3 scripts/build_series_assets.py --plan 01 --dry-run
```

### 2. 写文章

每篇文章的骨架占位文件已经建好（`01_买量三论.md` 等），直接在文件里填内容。风格参数调 AI 时把第五节的三层过滤 Prompt 贴上去。

### 3. 生成公众号排版 HTML

系列完稿后，参照 `drafts/` 下已有 html 文件的模板，把 Markdown 转成公众号适配的 HTML（或用 Typora + 主题导出，或用 `sources/` 下的现成脚本）。

### 4. 发布流程

- 文案：直接贴到公众号后台
- 图：先上传到公众号图床，替换 md/html 里的本地路径
- 发布前：过一遍 `反AI味提示词库.md` 第 8 章 Checklist
- 发布后：同步到 `sources/feishu_sync_log.json`（如果有对接飞书）
