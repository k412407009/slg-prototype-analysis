## 这个项目是什么

这是一套 **Steam 原型 → SLG 改造方向** 的筛选工具和分析方法论。

它回答的核心问题是：**哪些 Steam 游戏值得被改造成 SLG 手游出海？**

网站用真实数据（Steam 评论语言分布、峰值在线、销量区间、奖项记录）评估了 8 款原型，推导出 8 个候选方向（A–I），并给出了每个方向的档位评级（S+ / S / A+ / A / B+ / B / D）和立项评审分数。

## 数据是怎么形成的

### 原始数据来源

| 数据维度 | 来源 |
|---|---|
| 评论总数 / 各语言计数 | Steam 商店页的语言过滤器（逐语言手动筛选） |
| 峰值在线 | SteamDB（`steamdb.info`） |
| 销量区间 | SteamSpy（估算值） |
| 好评率 | Steam 商店页公开数据 |
| IP 奖项 / 电视剧背书 | Apple App Store Awards / Metacritic / Wikipedia |

> **为什么不用 API 或爬虫？** Steam 官方 API 对评论数据有严格限制，手动拉语言过滤器是最可靠的方式。本网站立身之本就是"不可验证不收录"，所以数据全部是人工核验的真实计数。

### 数据版本历史

| 版本 | 时间 | 核心变化 |
|---|---|---|
| v1 幻觉版 | 早期 | 常识估算语言分布，错误率极高（已淘汰） |
| v2 补交叉源 | 中期 | 加了 SteamDB/SteamSpy，但仍有估算值 |
| v3 真实数据版 | 2026-04-16 | 全部拉真实 Steam 语言计数 |
| v4 立项评审同步版 | 2026-04-20 | 新增立项评审分 + P0 清单 + §四章节 |

## 方向档位是怎么定的

每个方向的档位（S+ / S / A+ / A / B+ / B / D）由三维打分推导：

| 维度 | 5 分标准 | 打分原则 |
|---|---|---|
| **买量合规** | 所有主渠道（Meta / Google / AppLovin）均可投放 | 合规有硬边界：一票否决直接 D 档 |
| **海外盘大小** | 英语区 ≥ 10 万评论 + 多语言均衡 | 不均衡但某一语种极强 = 降档（如 Beholder 俄语 38%） |
| **SLG 改造空间** | 原作是单人经营骨架，无 PVP/联盟/多城 | 原作已是重度 TBS/SLG = 降档 |

**档位硬边界**（命中即触发降档，与三维分数无关）：
- 主渠道禁投 2 家以上 → 直接 D
- iOS/Android 100% 拒审 → 直接 D
- 英语区评论 < 20% → 至少降到 B
- 原作已有联盟/PVP/多城 → SLG 改造 ≤ 3 星

详见 [`docs/网站信息维护指南_WEBSITE_INFO_MAINTENANCE.md`](docs/网站信息维护指南_WEBSITE_INFO_MAINTENANCE.md) §3.5–§3.6。
