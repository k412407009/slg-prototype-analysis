# SLG 原型分析 · 轻量化海外赛道决策台

> 一个面向同事分享的公开整理版仓库。  
> 目标不是“展示一个漂亮网页”，而是把这套 **Steam 原型 → 赛道判断 → SLG 改造 → 立项筛选** 的方法，完整交给下一个人也能继续用。

## 这是什么

这是一套围绕 **“哪些 Steam 原型值得被改造成轻量化 SLG 并用于海外发行”** 展开的分析资料包，包含三层内容：

1. **网站层**：一个纯静态分析页面，把 8 个 Steam 原型、8 个候选方向、立项评审结果汇总成可视化网页。
2. **方法层**：一套可以复用的方法论，解释我们如何从“看起来有意思的题材”收敛到“值得继续立项的方向”。
3. **工作层**：维护手册、SOP 模板、投放札记，帮助后来者更新数据、复做分析、扩展到新赛道。

一句话说，这个仓库回答的是三件事：

- **这个网站怎么看？**
- **这些结论是怎么来的？**
- **如果下次要分析别的赛道，应该怎么照着做？**

## 网站该怎么看

主页面从上到下可以分成 4 层：

### 1. 原型层：先看“市场上什么东西已经被验证过”

这里展示 8 款 Steam 原型，每一张卡片回答的是：

- 它到底热不热
- 主要是哪些语言用户在玩
- 它的题材是不是跨文化成立
- 它值不值得被拿来继续拆

你不应该把它理解成“竞品分析展示墙”，而应该理解成：

> **这是候选题材的证据池。**

每个原型卡片里最重要的，不是峰值在线，也不是总评论，而是 **“语言分布 + 爽点类型 + 跨文化背书”** 的组合。

### 2. 聚合层：看“这个赛道的全球盘是不是成立”

地区汇总图不是为了证明某一个国家有多强，而是为了快速回答：

- 这个方向是不是只在局部市场成立
- 英语区是不是足够大
- 有没有明显的区域偏斜风险

例如：
- 英语区稳定占主盘，说明海外发行讨论有基础；
- 某个非英语语种异常高，说明它可能是区域化题材，而不是全球化题材。

### 3. 方向层：看“题材能不能改造成轻量化 SLG”

这是整页最核心的部分。

每个方向卡片本质上都在回答三个问题：

1. **买量合规吗？**
2. **海外盘够大吗？**
3. **SLG 改造空间够不够？**

所以方向卡片不是“创意脑暴”，而是 **立项预判结果**。

### 4. 评审层：看“这个方向值不值得继续推进”

最后一层是内部立项评审同步结果。它不再回答“题材有没有意思”，而是回答：

- 这个方案今天要不要继续投资源
- 哪些方向可以继续打磨
- 哪些方向应该停掉
- 每个方向的 P0 风险是什么

所以如果你是第一次看，建议：

- **先看方向层拿结论**
- **再看原型层看证据**
- **最后看评审层决定优先级**

## 这套数据是怎么形成的

### 数据不是“自动抓出来的结论”，而是“人工校验过的证据”

这套分析最重要的原则是：

> **不知道就写 unknown，不能验证就不收录。**

因此这里的数据形成方式偏“笨”，但可追溯：

- **Steam 评论语言分布**：来自 Steam 商店页的语言过滤器逐项核验
- **峰值在线**：用 SteamDB 交叉验证
- **销量区间**：用 SteamSpy 等公开来源做区间参考
- **移动端背书 / 题材外部验证**：用 App Store、Google Play、奖项、剧集、YouTube 等公开来源补足

### 我们实际在做的是“三段式证据拼装”

每个方向并不是凭直觉来的，而是由三种证据拼出来的：

1. **真实热度证据**：这个原型是否真的被市场验证过
2. **跨文化证据**：这个题材是否只在局部成立，还是能出海
3. **改造证据**：它能不能自然长出“休闲劳作 + 冲突 + 社交联盟”三层结构

只要其中一段证据不成立，这个方向就不应进入高优先级。

## 赛道改造方法到底是什么

这是你特别希望 README 里讲清楚的部分，我直接把核心逻辑写透。

### 先说结论

这套方法的核心，不是“找一个 Steam 爆款然后照抄”，而是：

> **从一个被验证过的原型里，拆出“跨文化爽点”，再把这个爽点改写进轻量化 SLG 的三段结构里。**

这三段结构是：

1. **日常劳作层**：玩家每天愿意反复做的轻度动作
2. **冲突升级层**：让个人经营自然过渡到资源争夺 / 外部威胁
3. **联盟社会层**：把单人循环推向多人协作与竞争

### 改造不是“换皮”，而是“爽点迁移”

以几个方向举例：

- **A 港口开箱** 不是简单复刻仓储拍卖，而是抓住“拆箱未知感”这个爽点，再把它放大成港口、多港争夺、海关博弈、黑市分发。
- **G 禁酒令私酒帝国** 不是直接搬 `Schedule I` 的题材，而是保留“生产—分销—扩张”的闭环爽感，把高风险毒品题材蒸馏成可买量、可发行的禁酒令私酒题材。
- **H 深海守望者** 不是做一个 DREDGE 手游版，而是提炼“白天出海/夜晚恐惧/深海未知”这套节律，再问它能不能长出港口建设、海域争夺、联盟合作。

### 一条简单的判断原则

如果一个题材只能支持“单机爽”，却长不出“集体诉求”，它就不适合往轻量化 SLG 推。

反过来，如果一个题材同时满足下面三件事，它通常值得继续：

- 天然有日常动作
- 天然有外部威胁
- 天然有抱团理由

这也是 [`methodology/SOP.md`](methodology/SOP.md) 的底层假设。

## 如果你想把它迁移到别的赛道，应该怎么做

不要直接复制这个 HTML 然后换几个名字。正确迁移顺序是：

### 第一步：先重建候选池

不是“我想到 3 个题材就开会”，而是先拉 10–20 个候选出来，按 SOP 第 1 周做五维打分。

### 第二步：用原型而不是用题材词做分析

不要直接分析“海盗”“丧尸”“中世纪”这种抽象题材词。

要分析的是：

- 哪些具体产品已经在这个题材里证明了用户会买单
- 这些产品到底是靠什么爽点吃到用户
- 这些爽点能不能迁移到你要做的结构里

### 第三步：永远先判合规，再谈天花板

题材越刺激，往往越容易让人误判它有高潜力。

但如果主流买量渠道和应用商店天然卡死，它就是纸面上的好题材，商业上不成立。方向 D 被降到 D 档，就是这个原因。

### 第四步：把“方向”写成可审计记录

真正可复用的方法，不是脑子里记得“好像这个不错”，而是每次都能回溯：

- 这个方向为什么入池
- 为什么升档
- 为什么降档
- 它的风险边界在哪里

这部分在 [`docs/网站信息维护指南_WEBSITE_INFO_MAINTENANCE.md`](docs/网站信息维护指南_WEBSITE_INFO_MAINTENANCE.md) 里有完整展开。
